# 세븐틴 가사 퀴즈 · SVT Lyrics Quiz

세븐틴 가사를 **음성(TTS)으로 듣고 원곡을 맞히는** 오프라인 팬 대상 퀴즈쇼 도구입니다.
사회자 1명 + 참가자 다수 구성의 소규모 모임(칼럿 모임)을 위해 만들어졌습니다.

> 설치·빌드·서버가 필요 없습니다. `index.html` 파일 하나로 동작합니다.

## 시작하기

1. `index.html`을 **Chrome 또는 Edge**로 엽니다. (한국어 TTS 음성 엔진 안정성 권장)
2. 바로 플레이할 수 있도록 40문항이 기본 내장되어 있습니다.
3. 사회자 화면을 참가자와 공유(미러링·프로젝터)하고 **가사 가리기**를 켜면 듣기 전용 모드가 됩니다.

배포하려면 이 저장소를 GitHub Pages로 게시하면 URL 하나로 접속할 수 있습니다.

## 게임 방법

가사 낭독(TTS) → 참가자 응답 → 정답 공개 → MV 해당 구간 재생 → 사회자 채점 → 다음 문항

- **가사 낭독 + 속도 조절(0.5~1.2배)** — 청각 단일 채널 유지. 느리게=난이도↓, 빠르게=난이도↑
- **가사 가리기 토글** — 화면에 가사를 흐리게 처리해 듣기만으로 변별
- **정답 공개** — 곡명·파트 표시 + 등록된 MV를 지정한 시작 시간부터 자동 재생
- **사회자 수동 채점** — 구어·약칭·표기 혼용 응답을 유연하게 인정
- **난이도 필터 / 셔플** — 상·중·신곡만 골라 출제하거나 순서를 랜덤화
- **타이머** — 문항별 제한 시간(설정 탭에서 on/off·초 조절)
- **팀전 모드** — 팀별 점수판·턴 관리, 타이머와 함께 켜면 남은 시간만큼 시간 보너스
- **결과·등급** — 정답률에 따라 입덕 준비생 🐣 → 칼럿 인증 🏆 등급 부여

## 문항 구성

- 총 **48문항** (상 17 / 중 23 / 신곡 8) — 기본 40문항 + 확장 8곡
- 초기 앨범 수록곡·유닛곡·솔로곡·최신곡을 두루 포함해 코어 팬을 변별
- 타이틀곡 후렴을 지양하고 벌스·랩·브릿지 위주로 파트를 선정
- 난이도 필터로 상/중/신곡만 골라 출제할 수 있어 문항 수는 자유롭게 조절됩니다

## 설정 탭에서 편집하기

곡명·파트·난이도·가사·MV 주소·시작 시간을 모두 편집할 수 있으며, 곡 추가/삭제도 가능합니다.
입력값은 브라우저 localStorage에 자동 저장됩니다.

- **가사**: 문항당 1~2줄 권장 (TTS 낭독 8~15초가 적정)
- **MV 주소**: `youtu.be`, `watch?v=`, `/embed/`, `/shorts/` 형식 모두 자동 인식
- **시작 시간**: `1:12` 또는 초 단위 정수(`72`) — 해당 가사보다 **3~5초 앞**을 권장
- **일괄 입력**: `1. 가사` 형식 텍스트를 붙여넣어 슬롯에 자동 배분
- **JSON 내보내기/불러오기**: 기기 간 이동·백업
- **기본값 복원**: 내장 40문항·설정으로 초기화

## 데이터에 관한 안내

- **가사 48곡 중 40곡이 기본 입력**되어 있으며, 입력된 40곡은 여러 가사 출처와 **교차검증**을 마쳤습니다.
  다만 팬 퀴즈용 짧은 발췌이므로 띄어쓰기 등 미세한 차이가 있을 수 있어 **공연 전 확인**을 권장합니다.
- 아직 비어 있는 8곡은 제목이 후렴에 포함되거나(즉답 처리) 영어·스캣 위주라 발췌가 적절치 않아
  비워 두었습니다. 설정 탭에서 원하는 구절을 직접 채워 넣으세요:
  **Trauma · Space(끝이 안보여) · Shhh · 박수(CLAP) · 어쩌나(Oh My!) · 거침없이 · Spell · Bad Influence**
- MV 주소는 공식 유튜브 영상이 있는 곡에 기본 등록되어 있습니다.
- **시작 시간(타임스탬프)은 추정값입니다.** MV를 직접 확인할 수 없어 곡 길이·파트 위치로 "가사보다 약 3초 앞"을
  추정해 넣었습니다. 실제 시점과 다를 수 있으니 **리허설 때 반드시 보정**하세요(설정 탭에서 `1:12` 형식으로 수정).

## 좋은 구절 선정 가이드

- 곡명·제목 키워드가 포함되지 않은 구간 (곡명이 나오면 즉답 처리됨)
- 후렴보다 벌스·브릿지, 문장이 완결되어 낭독 시 의미가 통하는 단위
- 영어 비중이 높거나 의성어·추임새 위주인 구간은 지양 (한국어 TTS 발음·정보량 문제)
