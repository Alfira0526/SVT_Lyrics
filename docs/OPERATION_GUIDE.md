# 🎙️ 운영 가이드 (사회자용)

세븐틴 가사 퀴즈를 오프라인 모임에서 진행하기 위한 실전 가이드입니다.

---

## 1. 준비 (모임 전 1회)

- [ ] **환경 점검** — 노트북 + Chrome/Edge, 프로젝터/모니터 미러링, 스피커 볼륨
- [ ] **가사 낭독 테스트** — 게임 탭에서 `▶ 가사 낭독`을 눌러 한국어 음성이 나오는지 확인
      (안 나오면 [FAQ](../README.md#-자주-묻는-질문-faq) 참고)
- [ ] **MV 재생 테스트** — `정답 공개`를 눌러 유튜브 영상이 지정 시점부터 재생되는지 확인
- [ ] **타임스탬프 보정** — 기본값은 추정치이므로, 사용할 문항의 시작 시간을 설정 탭에서 미세 조정
- [ ] **저장 슬롯 백업** — 설정 탭 → **저장 슬롯**(🔒 비밀번호 `19950719`)에서 현재 구성을 이름 붙여 저장, 필요 시 `불러오기(파일)`로 복원

> 문항 내용을 바꾸고 싶다면 설정 탭에서 곡·가사·MV·시간을 자유롭게 편집하세요.
> 데이터 규격은 [데이터 스펙](DATA_SPEC.md)을 참고합니다.

## 2. 게임 시작 흐름 · 방식 선택

랜딩 화면에서 **▶ 시작하기**를 누르면 **기본 설정(게임 옵션)** 화면으로 이동합니다.
여기서 옵션을 정하고 **▶ 게임 시작**을 누르면 (자동 셔플 1회 + 타이머가 켜져 있으면) 게임이 시작됩니다.

**기본 설정 화면 옵션**
- **문제 수** — 뽑을 문항 수 선택(+`유닛곡 비중 높이기`로 유닛곡 가중 추첨)
- **타이머** — `타이머 사용` 켜기 + 제한 시간(초). 게임 시작과 함께 카운트다운 시작
- **팀전** — `팀전 모드` 켜기 + 팀 이름 설정. 타이머와 함께 쓰면 **남은 시간만큼 보너스 점수**
- **4지선다** — 문항마다 곡명 보기 4개 중 정답 고르기

**개인전 vs 팀전 채점 방식**
- **개인전/솔로(먼저 맞히기)** — 4지선다에서 **먼저** 보기를 고르면 즉시 정답/오답 판정. 다수에게 화면을 보여주며 진행하거나 혼자 플레이할 때 적합.
- **팀전(팀별 순차 선택)** — 팀이 **2개 이상**이면 각 팀이 **차례대로** 보기를 하나씩 선택합니다(화면에 `🎤 팀X 차례` 표시). 모든 팀이 고르면 **자동 채점** — 정답을 고른 팀마다 +1점(타이머 시 남은 시간 보너스 가산). 다음 문항은 **다음 팀부터** 시작해 순서가 공평하게 순환됩니다.
  - 4지선다를 끄면(팀전만) 기존처럼 **정답 공개 후 맞힌 팀 버튼**으로 수동 채점합니다.
- **팀 선택 가리기**(기본 ON, 기본 설정 화면 토글) — 두 가지 운영을 모두 지원합니다.
  - **오프라인**(팀별 논의 후 선택): 순서·우선순위가 중요치 않으므로 켜두거나 꺼도 됩니다. 끄면 각 팀 선택이 화면에 배지로 바로 표시됩니다.
  - **온라인·동시 진행**: 켜두면 **모든 팀이 고를 때까지 각 팀 선택을 비공개**로 유지 → 먼저 고른 팀 선택이 다른 팀에 드러나지 않습니다.
  - ⚠️ 이 앱은 단일 화면 기반이라 각 팀이 개별 기기에서 실시간 동시 입력하는 진짜 멀티플레이는 지원하지 않습니다(별도 서버 필요). 가리기 모드는 **한 화면으로 진행할 때 선택이 노출되지 않도록** 하는 용도입니다.

> 게임 옵션은 **기본 설정 화면**에 모여 있고, 설정 탭에는 **곡·가사 편집**과 **저장 슬롯**만 남아 있습니다.

## 3. 진행 순서 (문항 반복)

```
1) 가사 가리기 ON  → 화면엔 가사가 흐리게(듣기 전용)
2) 카드 전환        → 새 문항으로 넘어가면 2초 뒤 가사가 자동 낭독됨
                     (필요하면 ▶ 가사 낭독으로 다시, 속도를 낮춰 재낭독도 가능)
3) 응답/선택        → 개인전: 먼저 맞히기 · 팀전+4지선다: 각 팀이 차례대로 보기 선택
4) 정답 공개/채점    → 개인전: 정답/오답 버튼 · 팀전: 모든 팀 선택 시 자동 채점
                     (4지선다 끈 팀전은 정답 공개 후 맞힌 팀 버튼) + MV 재생
5) 다음 →          → 반복(팀전은 다음 팀부터 시작)
```

**진행 팁**
- 문항을 넘기면 **2초 뒤 자동으로 가사가 낭독**됩니다. 곧바로 다시 들려주려면 `▶ 가사 낭독`을 누르세요.
- 난이도를 높이려면 낭독 속도를 올리고, 낮추려면 0.5~0.7배로 천천히 읽어줍니다.
- `가사 가리기`를 끄면 화면의 가사를 함께 보여줄 수 있어 초보 팬 모임에 적합합니다.
- 상단 **난이도 필터**로 "상만", "신곡만" 같은 특별 라운드를 운영할 수 있습니다.
- **셔플**로 순서를 섞으면 재플레이 시 신선합니다.

## 6. 문제 해결 빠른 참고

| 증상 | 조치 |
|---|---|
| 낭독 소리 없음 | Chrome/Edge 사용, OS 한국어 음성 설치 확인, 화면 한 번 클릭 후 재시도 |
| MV 안 나옴 | 설정 탭에서 MV 주소 입력/수정, 정답 공개(클릭) 이후 자동재생됨 |
| 시작 시간 어긋남 | 설정 탭에서 `1:12` 형식으로 보정 (기본값은 추정치) |
| 데이터 초기화됨 | 브라우저 사이트 데이터 삭제 시 소실 → **저장 슬롯**에 백업 습관화 |
| 다른 기기에도 반영하려면 | 저장 슬롯 → **💾 배포본 저장(커밋용)**으로 받은 `svt-data.json`을 저장소에 커밋 |
