# 🎙️ 운영 가이드 (사회자용)

세븐틴 가사 퀴즈를 오프라인 모임에서 진행하기 위한 실전 가이드입니다.

---

## 1. 준비 (모임 전 1회)

- [ ] **환경 점검** — 노트북 + Chrome/Edge, 프로젝터/모니터 미러링, 스피커 볼륨
- [ ] **가사 낭독 테스트** — 게임 탭에서 `▶ 가사 낭독`을 눌러 한국어 음성이 나오는지 확인
      (안 나오면 [FAQ](../README.md#-자주-묻는-질문-faq) 참고)
- [ ] **MV 재생 테스트** — `정답 공개`를 눌러 유튜브 영상이 지정 시점부터 재생되는지 확인
- [ ] **타임스탬프 보정** — 기본값은 추정치이므로, 사용할 문항의 시작 시간을 설정 탭에서 미세 조정
- [ ] **저장 슬롯 백업** — 설정 탭 → **저장 슬롯**(🔒 비밀번호 `19950719`)에서 현재 구성을 이름 붙여 저장, 필요 시 `불러오기(파일)`로 복원

> 문항 내용을 바꾸고 싶다면 설정 탭에서 곡·가사·MV·시간을 자유롭게 편집하세요.
> 데이터 규격은 [데이터 스펙](DATA_SPEC.md)을 참고합니다.

## 2. 게임 시작 흐름 · 방식 선택

랜딩 화면에서 **▶ 시작하기**를 누르면 **기본 설정(게임 옵션)** 화면으로 이동합니다.
여기서 옵션을 정하고 **▶ 게임 시작**을 누르면 (자동 셔플 1회 + 타이머가 켜져 있으면) 게임이 시작됩니다.

**기본 설정 화면 옵션**
- **문제 수** — **−/+ 로 5문제 단위** 조절 또는 **전체** 선택(+`유닛곡 비중 높이기`로 유닛곡 가중 추첨)
- **타이머** — `타이머 사용` 켜기 + 제한 시간(초). 게임 시작과 함께 카운트다운 시작
- **팀전** — `팀전 모드` 켜기 + 팀 이름 설정. **🎲 랜덤 이름**을 누르면 세븐틴 케미 조합명(호우주의보·댕냥즈·최씨즈·부석순 등)으로 팀명을 자동 배정. 타이머와 함께 쓰면 **남은 시간만큼 보너스 점수**
- **4지선다** — 문항마다 곡명 보기 4개 중 정답 고르기
- **문제만 맞추기** — 정답 공개 시 **영상 없이 정답만** 표시하고 바로 다음으로. **자동 TTS 낭독도 끕니다**(호스트·참가자 폰 모두). 같은 공간에서 폰으로 빠르게 돌릴 때(감상보다 회전율) 적합
- **🆕 새 문제로 이어가기**(결과 화면) — 지금까지 나온 문항을 빼고 새로 뽑아 이어서 진행(점수 유지). 여러 라운드를 겹치는 문제 없이 이어갈 수 있어요. **온라인 방이면 접속 중인 참가자도 함께 새 라운드로 이동**합니다. 남은 새 문제가 설정한 문제 수(5단위)보다 적으면 **남은 개수만큼만** 출제돼요

**개인전 vs 팀전 채점 방식**
- **개인전/솔로(먼저 맞히기)** — 4지선다에서 **먼저** 보기를 고르면 즉시 정답/오답 판정 + **자동 채점**(정답률 카운터에 바로 반영, 수동 버튼 불필요). 4지선다를 끄면 정답 공개 후 정답/오답 버튼으로 수동 채점. 다수에게 화면을 보여주며 진행하거나 혼자 플레이할 때 적합.
- **팀전(팀별 순차 선택)** — 팀이 **2개 이상**이면 각 팀이 **차례대로** 보기를 하나씩 선택합니다(화면에 `🎤 팀X 차례` 표시). 모든 팀이 고르면 **자동 채점** — 정답을 고른 팀마다 +1점(타이머 시 남은 시간 보너스 가산). 다음 문항은 **다음 팀부터** 시작해 순서가 공평하게 순환됩니다.
  - 4지선다를 끄면(팀전만) 기존처럼 **정답 공개 후 맞힌 팀 버튼**으로 수동 채점합니다.
- **팀 선택 가리기**(기본 ON, 기본 설정 화면 토글) — 두 가지 운영을 모두 지원합니다.
  - **오프라인**(팀별 논의 후 선택): 순서·우선순위가 중요치 않으므로 켜두거나 꺼도 됩니다. 끄면 각 팀 선택이 화면에 배지로 바로 표시됩니다.
  - **온라인·동시 진행**: 켜두면 **모든 팀이 고를 때까지 각 팀 선택을 비공개**로 유지 → 먼저 고른 팀 선택이 다른 팀에 드러나지 않습니다.
  - ⚠️ 이 앱은 단일 화면 기반이라 각 팀이 개별 기기에서 실시간 동시 입력하는 진짜 멀티플레이는 지원하지 않습니다(별도 서버 필요). 가리기 모드는 **한 화면으로 진행할 때 선택이 노출되지 않도록** 하는 용도입니다.

**자동 진행(오토 호스트)** — 사람 진행자 없이 게임을 스스로 굴립니다.
- 켜면 **낭독 → 카운트다운 → 정답 공개 → (4지선다) 자동 채점 → 다음**이 저절로 반복됩니다.
- 화면의 **▶/⏸/⏭** 컨트롤은 **방장(진행 화면)** 용 보조 장치 — 안 눌러도 진행되며, 중간에 멈추거나 건너뛸 때만 씁니다.
- **진행 컨트롤 숨기기**(키오스크)를 켜면 버튼 없이 순수 자동으로만 돕니다.
- ⚠️ 브라우저 정책상 **첫 「게임 시작」 탭 1회**는 필요합니다(그 뒤로는 자동). 팀별 점수 자동 집계까지 원하면 각 팀의 답 입력(순차 탭 또는 향후 온라인 방)이 있어야 합니다.

**온라인 방(각 팀 폰 참가) · 실험적** — 같은 공간에서 방장 PC로 방을 열고, 각 팀이 자기 폰으로 참가해 답을 제출합니다.
- **먼저 팀을 정하세요**: 기본 설정 팀전 카드에서 팀 수·이름 설정(🎲 랜덤 이름 가능). 이 팀들이 **참가자가 고를 선택지**가 됩니다.
- 방장이 **온라인 방** ON → 게임 시작 → **참가자 대기(로비)** 화면에 **방 코드·QR·연결 상태**가 뜹니다.
- 각 팀은 폰에서 랜딩의 **🔗 방 참가**로 **방 코드 입력 → 팀을 드롭다운에서 선택**(로비의 **📷 QR 스캔**이면 코드 자동 입력).
  - **팀당 1명 독점**: 이미 선택된 팀은 비활성 처리되고, 동시에 고르면 먼저 고른 사람이 차지합니다.
- 모두 모이면 방장이 **▶ 게임 시작** → 각 폰에 **문항 가사·힌트·보기(A/B/C/D)** 가 뜨고, 각 팀이 **자기 폰에서 비공개 제출**.
- **모든 팀이 제출하는 즉시**(또는 타이머 종료 시) **자동 정답 공개·자동 채점** → 각 폰에 정답·MV·순위가 전송되고 다음 문항으로. **방장은 답을 고르지 않습니다.**
- **원격(다른 공간)도 지원**: 참가자 폰이 **가사·▶듣기(TTS)·힌트·⏱️타이머·정답 MV** 를 모두 받아 자체적으로 진행할 수 있습니다(호스트 화면을 못 봐도 OK). 낭독은 **가사 언어를 자동 판별**해 영어 가사는 영어 성우, 한국어 가사는 한국어 성우로 읽습니다.
- **연결 상태 표시**: `🌐 릴레이 연결됨`이면 다른 기기 참가 가능, `💻`면 같은 브라우저(멀티탭)만 연결된 상태입니다.
- **진행 중 컨트롤**: 게임 화면 하단에 **⏹ 게임 종료(결과)** 와 **🏠 처음으로** 버튼. 종료 시 참가자 폰에도 "게임 종료·최종 순위"가 전송됩니다.
- **라운드 이어가기**: 한 판이 끝나 **결과** 화면에서 **🆕 새 문제로 이어가기**를 누르면 **방을 닫지 않고** 같은 참가자들과 새 문항으로 이어집니다(점수 유지). 참가자 폰에는 라운드 종료 안내가 떴다가 새 문항이 자동으로 도착해요. ⏹ **게임 종료**를 눌러야 방이 닫힙니다.

### 🔒 안정적 원격 — 무료 Firebase 연결(권장)
공개 릴레이가 불안정하면(상단이 `💻`만 뜨거나 제출이 취합 안 되면) 무료 **Firebase Realtime Database**를 쓰면 확실합니다.
1. [Firebase 콘솔](https://console.firebase.google.com)에서 무료 프로젝트 생성 → **Realtime Database** 만들기(테스트 모드=규칙 `read/write: true`)
2. DB 주소(`https://<프로젝트>.firebaseio.com` 또는 `...firebasedatabase.app`)를 복사
3. 기본 설정 화면 **온라인 방** 카드의 `Firebase Realtime DB 주소`에 붙여넣기 → **저장 슬롯 → 💾 배포본 저장**으로 커밋하면 모든 기기가 이 주소로 안정 동기화
   - 넣으면 그 경로로 확실히 연결(EventSource 스트리밍), 비우면 공개 릴레이로 동작합니다.
> ⚠️ 어떤 경우든 **리허설에서 실제 폰들로 사전 테스트**하고 상단이 `🌐`로 뜨는지 확인하세요.

> 게임 옵션은 **기본 설정 화면**에 모여 있고, 설정 탭에는 **곡·가사 편집**과 **저장 슬롯**만 남아 있습니다.

## 3. 진행 순서 (문항 반복)

```
1) 가사 가리기 ON  → 화면엔 가사가 흐리게(듣기 전용)
2) 카드 전환        → 새 문항으로 넘어가면 2초 뒤 가사가 자동 낭독됨
                     (필요하면 ▶ 가사 낭독으로 다시, 속도를 낮춰 재낭독도 가능)
3) 응답/선택        → 개인전: 먼저 맞히기 · 팀전+4지선다: 각 팀이 차례대로 보기 선택
4) 정답 공개/채점    → 개인전: 정답/오답 버튼 · 팀전: 모든 팀 선택 시 자동 채점
                     (4지선다 끈 팀전은 정답 공개 후 맞힌 팀 버튼) + MV 재생
5) 다음 →          → 반복(팀전은 다음 팀부터 시작)
```

**진행 팁**
- 문항을 넘기면 **2초 뒤 자동으로 가사가 낭독**됩니다. 곧바로 다시 들려주려면 `▶ 가사 낭독`을 누르세요.
- 난이도를 높이려면 낭독 속도를 올리고, 낮추려면 0.5~0.7배로 천천히 읽어줍니다.
- `가사 가리기`를 끄면 화면의 가사를 함께 보여줄 수 있어 초보 팬 모임에 적합합니다.
- 상단 **난이도 필터**로 "상만", "신곡만" 같은 특별 라운드를 운영할 수 있습니다.
- **셔플**로 순서를 섞으면 재플레이 시 신선합니다.

## 4. 마무리

- **결과** 탭에서 정답률·등급, 난이도별 정답 분해를 확인합니다.
- 팀전·온라인 방이면 팀 순위가 **등수(1위·2위…) + 메달(🥇🥈🥉)**로 표시됩니다(동점은 같은 등수).
- `다시 시작`으로 점수를 초기화하고 새 판을 시작할 수 있습니다.

## 6. 문제 해결 빠른 참고

| 증상 | 조치 |
|---|---|
| 낭독 소리 없음 | Chrome/Edge 사용, OS 한국어 음성 설치 확인, 화면 한 번 클릭 후 재시도 |
| MV 안 나옴 | 설정 탭에서 MV 주소 입력/수정, 정답 공개(클릭) 이후 자동재생됨 |
| 시작 시간 어긋남 | 설정 탭에서 `1:12` 형식으로 보정 (기본값은 추정치) |
| 데이터 초기화됨 | 브라우저 사이트 데이터 삭제 시 소실 → **저장 슬롯**에 백업 습관화 |
| 다른 기기에도 반영하려면 | 저장 슬롯 → **💾 배포본 저장(커밋용)**으로 받은 `svt-data.json`을 저장소에 커밋 |
