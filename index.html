👥 팀 수 · 팀 대결·온라인 대결을 이 수로 나눠요
2~8팀까지 정할 수 있어요. 팀 대결·온라인 대결을 고르면 이 팀 수로 시작해요 🙌
팀 이름을 직접 바꾸려면 아래 세부 설정 · 팀에서 편집하세요.
🎧 듣기 전용 (가사 가리기) · 권장
이 게임의 핵심 모드예요. 화면의 가사를 가리고 TTS 낭독만 듣고 곡을 맞혀요 — 눈으로 읽는 것보다 변별력이 훨씬 높아요.
초보 팬 모임이라 가사를 함께 보여주고 싶으면 꺼도 돼요(진행 중 가사 가리기 토글로도 전환 가능).
문제 수 · 팀전·온라인 전용 (개인은 20문제 고정)
문제 수는 5문제 단위로 −/+ 조절할 수 있어요. 처음 모이는 자리라면 10~15문제로 가볍게, 제대로 겨뤄보려면 전체를 추천해요 🎯
유닛곡 비중을 켜두면 부석순·호시우지 같은 유닛곡이 더 자주 나와요.
🎯 문제 범위 (그룹 선택)
전체 난이도 구성
특정 그룹만 골라 출제할 수 있어요 — 난이도(상·중·신곡), 구성(완전체·유닛곡).
예: 가볍게 즐길 땐 중·신곡, 고인물끼리는 상·유닛곡으로 난이도를 조절하세요. 게임 중에도 상단 난이도 칩으로 바꿀 수 있어요.

팀전 모드 (팀별 점수 대결)
여럿이 모였다면 팀전을 켜보세요 🙌 각 팀이 맞히면 1문제 = 1점씩 쌓여 팀별 점수로 순위를 매겨요.
혼자 또는 각자 겨루는 자리라면 꺼두어도 좋아요.
4지선다 (객관식) — 보기 4개 중 정답 고르기 · 변별력↓
팀 선택 가리기 (팀전 4지선다 · 동시/온라인)
문제만 맞추기 (영상·자동낭독 없이 · 빠른 진행 · 변별력↓)
감이 잘 안 올 땐 보기 4개가 있으면 훨씬 수월해요. 어려운 모드는 OFF 🔥
팀 선택 가리기를 켜면 팀전에서 각 팀 선택이 모두 고를 때까지 비공개돼요.
문제만 맞추기: 같은 공간에서 폰으로 빠르게 돌릴 때 좋아요 — 답만 다 고르면 정답만 공개(영상 생략)하고 바로 다음으로.
⚙️ 고급 설정 · 자동 진행 · 온라인 방 · 음성 확인
자동 진행 (오토 호스트) — 사람 진행자 없이
진행 컨트롤 숨기기 (키오스크)
자동 진행을 켜면 낭독 → 카운트다운 → 정답 공개 → 다음이 저절로 흘러가요 🤖 진행자가 필요 없어요.
화면의 ▶/⏸/⏭ 컨트롤은 방장(진행 화면) 용 보조 장치 — 안 눌러도 진행돼요. 컨트롤 숨기기를 켜면 버튼 없이 순수 자동(키오스크)으로 돌아가요.
온라인 방 (각 팀 폰 참가) · 실험적 · 인터넷 연결 필요
켜면 게임 시작 시 방 코드가 뜨고, 각 팀은 폰에서 🔗 방 참가로 코드를 입력해 들어와요. 각 팀이 자기 폰에서 비공개 제출 → 방장 화면 자동 채점.
원격(다른 공간)도 지원: 참가자 폰이 가사·힌트·듣기·타이머·정답 MV를 모두 받습니다. 전송은 같은 브라우저=즉시, 다른 기기=공개 릴레이(베스트에포트).
🔒 안정적 원격이 필요하면 무료 Firebase Realtime DB 주소를 넣으세요(규칙 test 모드). 넣으면 그 경로로 확실히 동기화되고, 비우면 공개 릴레이로 동작합니다.
